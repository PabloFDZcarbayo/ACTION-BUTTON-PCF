## [1.0.0] - 2026-03-26

### Añadido
- Control PCF inicial con botón personalizable de FluentUI
- Soporte para ejecutar funciones JavaScript globales
- Soporte para ejecutar Custom APIs de Dynamics 365
- Propiedad configurable para tipo de botón (Primary/Secondary)
- Propiedad configurable para etiqueta del botón
- Propiedad opcional para función JavaScript
- Propiedad opcional para Custom API
- Propiedad para deshabilitar el botón
- Manejo de errores con notificaciones al usuario
- Documentación completa en README.md
- Guía de inicio rápido en QUICKSTART.md
- Ejemplos de funciones JavaScript
- Ejemplos de Custom APIs
- Configuración de VS Code para desarrollo
- Configuración de TypeScript y ESLint

### Características principales
- ✅ Basado en FluentUI React v8 para compatibilidad con Dynamics 365
- ✅ Totalmente tipado con TypeScript
- ✅ Compatible con Dynamics 365 / Power Apps
- ✅ Soporte para contexto de formulario en funciones JS
- ✅ Integración con Web API de Dynamics
- ✅ Notificaciones de éxito/error automáticas
- ✅ Refresco automático del formulario después de ejecutar Custom API
